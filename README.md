# Harismitha Devi Goriparthi | Portfolio

Personal portfolio website of **Harismitha Devi Goriparthi**, a B.Tech Electronics and Communication Engineering student (Class of 2027) at Vel Tech University, Chennai.

**Live site:** https://harismithagoriparthi219.github.io/portfolio/

## About

I build embedded systems and AI-powered software. My work covers ESP32, Arduino and AVR firmware with RTOS basics, and Python applications using OpenCV, Flask and MySQL.

## Projects shown on the site

- **Fresh Fruit and Vegetable Detection System:** OpenCV-based model that classifies produce as fresh or rotten. Python, OpenCV, Machine Learning.
- **E-Commerce Web Application:** login authentication and product modules backed by MySQL. Flask, Python, MySQL, HTML, CSS.
- **Smart Fish Aggregation Detection System:** ESP32 with an ultrasonic sensor, buzzer and LED alerts, and live Wi-Fi monitoring through Blynk. ESP32, Embedded C, Blynk.
- **Embedded Systems and RTOS:** firmware and sensor interfacing with I2C, SPI, UART and CAN.
